## 2026-05-07

### プロダクト再定義：「AI カメラマン」

このアプリは「ポーズ提案アプリ」ではなく **「AI カメラマン」** として撮影ディレクションを代行するプロダクト、と明確に再定義。提案するのは「ポーズ」ではなく **「状態（姿勢 + 構図）」**。詳細は [design.md](design.md)。

### 確定した設計事項

- **盛れる = 状態の最適化**：顔角度・体の傾き・手の余白・カメラ距離・背景関係。「腰に手を当てる」ではなく「顔が小さく見える角度 + 立体感 + 余白調整」
- **状態テンプレート（StateTemplate）**：完成した写真のスナップショットを構造化データで保持。`subject` / `composition` / `background_hint` の 3 ブロック。`background_hint` は MVP では未使用、フィールドのみ予約
- **テンプレ作成方針**：P1 は手作り 5 個（自分 or 友人で撮影 → MediaPipe で関節抽出 → 手で微調整）。P2 でコーパス収集、P3 で半自動生成
- **シルエット**：半透明人体 + 関節マーカーのハイブリッド（スティックは抽象すぎ、完全人体は合わせづらい）
- **補間**：最近傍テンプレへ 0.1〜0.2 秒で線形補間。ヒステリシスで切り替え抑制
- **セッション**：1 起動 = 5〜10 枚。同じテンプレを連続選択しない。フォルダ化保存
- **失敗を見せない**：スコアが上がらない時は近傍テンプレに気づかれず切り替え
- **起動体験**：完全無言開始。0.2 秒以内に人物検出 → シルエット出現 → 視覚フィードバック開始
- **オンボーディング**：初回のみ 3 秒、「かざすだけで、自動でいい写真を撮ります」、タップで消える
- **指示優先順位**：視覚 > 触覚 > 音声（音声はデフォルト OFF、設定で ON）
- **初期ターゲット**：他撮り（撮影者が画面、被写体が指示を受ける）
- **良い顔判定**：MVP では「顔検出 + 目開き + 角度範囲内」のみ。笑顔判定は後回し
- **残す操作**：ピンチズーム、端末回転、フラッシュ。**隠す**：モード切替、ポーズ選択、手動シャッター
- **将来候補**：Apple Watch 連携での被写体振動指示（公共空間での音声代替）

### 開発フローの確定：「体験 → AI」の順

ロードマップを「体験プロトタイプ → MVP（非 AI）→ AI 導入 → コア機能 → UX 改善 → 撮影体験拡張 → リリース」の 7 フェーズに再構成。

- **P0：体験プロトタイプ（最重要）** — AI なし、ダミーで「AI カメラマンっぽさ」を検証。**1 日で終わらせる**
- **P1：MVP（非 AI）** — 実カメラ + ダミー PoseEstimator で UX を完成させる
- **P2：AI 導入** — MediaPipe / Vision でダミーを実データに置換

判断基準：**「ここで面白くなければ、AI を入れても面白くならない」**。先に体験の骨格を確定させ、AI は後から差し込む。技術ではなく体験を作るプロジェクトとして開発する。

`CLAUDE.md` に開発方針セクションを追記。`docs/roadmap.md` を全面改訂。

### P0 プロトタイプ実装後の重要な方針修正：「セッション」の廃止

P0 プロトタイプを実装した後、設計の根本にズレがあることが判明：

- ❌ **修正前**：`1 起動 = 5 枚撮影 → セッション完了 → "もう一度" ボタン`
  → これは「撮影体験が区切られている」状態。**体験アプリ寄り**
- ⭕ **修正後**：`常時稼働 LIVE → 撮影は LIVE 内のイベント → 即 LIVE 継続`
  → 「**撮らせる**」ではなく「**撮れてしまう**」

#### 中核の言語化

このアプリは **「普通のカメラ + AI レイヤー」**。ユーザーから見えるのは普通のカメラ、AI は完全に裏で動く。「セッション」「完了」「次へ」「終了」という概念を持たない。

#### コードの修正

- `CaptureState`：`.preview` `.ended` を削除。`.idle` `.searching` `.guiding` の 3 状態のみ
- `CameraViewModel`：`sessionTotalShots` を廃止。`runLive()` で無限ループ。撮影後は即 guiding に戻る
- `CameraScreen`：feedback を上に小さく配置、シルエット opacity を 0.55 → 0.25 に薄く、保険のシャッターボタンを下に追加、「もう一度」ボタンを削除、撮影後のプレビュー画面を削除（隅にサムネが一瞬出るのみ）

#### ドキュメントの修正

- `docs/design.md` §5 を `CaptureSession` から `Live Stream：常時稼働モデル` に書き換え
- `CLAUDE.md` のコアコンセプトに「常時稼働カメラ + AI レイヤー」「撮らせるではなく撮れてしまう」「流れを切らない」を追加。状態モデルを `SEARCH → GUIDE → CAPTURE` から「終わらない LIVE」に変更
- `docs/roadmap.md` P5 のセッション関連記述を「即時 LIVE 復帰 / 累積カウンタ」に書き換え

#### 学び

P0 を実機で触ってフィードバックを得ることの価値が大きい。「動くもの」を作って初めて見える設計の歪みがある。これが **「体験 → AI の順で作る」** 開発方針の正当性を裏付ける。
