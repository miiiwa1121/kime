# ロードマップ

## ビジョン

ユーザーが **「何も考えずにいい感じの写真が撮れる」** と感じる体験を実現する。
単なるカメラアプリではなく **リアルタイムディレクションシステム**。

最終目標：**App Store でのリリース**。

---

## フェーズ 1：MVP（最優先）

**目的：最小構成で「体験が成立する」こと**

- [ ] カメラプレビュー表示（AVFoundation）
- [ ] フレーム取得（CMSampleBuffer）
- [ ] MediaPipe 統合（iOS 向け）
- [ ] 人体ランドマーク取得（最低：肩・首・顔）
- [ ] 仮ポーズ 1 種をハードコードで定義
- [ ] シルエット表示（オーバーレイ）
- [ ] ポーズ一致判定（関節角度 or 相対位置）→ 0〜1 スコア
- [ ] スコアに応じたフィードバックテキスト表示
  - 低 →「もう少し右！」／中 →「いい感じ！」／高 →「完璧！」
- [ ] 自動シャッター（スコア閾値以上を 0.5 秒維持で撮影）
- [ ] 写真の保存（カメラロール）

### 完了条件

カメラを起動 → ポーズに合わせる → 自動で撮影 → 写真が保存される、までがエラーなく一気通貫で動くこと。

---

## フェーズ 2：基本機能拡張

- [ ] ポーズ DB 導入（JSON 形式、複数ポーズ管理）
- [ ] レコメンドエンジン（人数・距離・タグでポーズ自動選択）
- [ ] ステートマシン実装（`SEARCH → GUIDE → CAPTURE`）
- [ ] 関節ごとの個別フィードバック（「あごを引いて」等）
- [ ] 顔向き判定（Vision Framework）の組み込み

### 完了条件

異なる構図（自撮り / 他撮り / 全身 / 上半身）で適切にポーズが切り替わり、ストレスなく撮影できること。

---

## フェーズ 3：UX 改善

- [ ] シルエット補正（ユーザー位置への追従、スケール調整）
- [ ] スコアスムージング（揺らぎ抑制）
- [ ] ポーズ切り替え制御（頻繁な切り替えを抑制するヒステリシス）
- [ ] 褒め文言バリエーション拡充（飽きさせない）
- [ ] シャッター瞬間の演出（音・振動・アニメーション）
- [ ] パフォーマンス最適化（発熱・バッテリー）

### 完了条件

10 分使い続けても発熱・バッテリーが許容範囲内、かつ「気持ちよさ」が破綻しないこと。

## 課題・リスク（要監視）

### 技術
- MediaPipe iOS の SPM 統合方法（CocoaPods 公式で SPM 例が少ない）
- リアルタイム精度と発熱のバランス
- 姿勢推定の安定性（暗所・逆光・遮蔽）

### UX
- ポーズ切り替えタイミング（頻繁すぎ／遅すぎ）
- 過剰な指示によるストレス
- 初期ポーズの質（最初の数枚で判断される）

### プロダクト
- SNOW / SODA / Ulike との差別化を体験で示せるか
- 初回起動時のインパクト
